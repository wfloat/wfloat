# Install Wfloat

In your web application:

```sh
npm install @wfloat/wfloat-web
```

Import Wfloat in browser-side code. Use a bundler with module-worker support, such as Vite; do not load models during server rendering. Microphone capture requires HTTPS or localhost. Start audio playback or microphone capture from a user interaction.

**Next: [choose a model](https://wfloat.com/models)** and follow its Web example. See [model management](../reference/model-management.web.md) for download progress and cleanup.
