# Documentation

[Install Wfloat](how-to/installation.web.md), then [choose a model](https://wfloat.com/models). Model pages provide the shortest working example; these pages describe the SDK API.

- [Model management](reference/model-management.web.md): downloads, progress, storage, and cleanup.
- [Language model](reference/language-models.web.md): messages, generation, tools, and structured output.
- [Text to speech](reference/text-to-speech.web.md): audio generation, dialogue, and playback.
- [Speech to text](reference/speech-to-text.web.md): recordings and live transcription.
- [Voice activity detection](reference/voice-activity-detection.web.md): speech ranges and live detection.

Choose Web, React Native, or Python at the top of a reference page. Your selection carries across the docs.
